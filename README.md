# RFID Scanning Ladder Trolley — 3D concept

Interactive 3D model of a 6 m mobile RFID scanning ladder: a castored trolley base, an aluminium mast, a 500×400×240 mm electrical panel holding a Zebra FX9600-8 reader, and 8 UHF panel antennas.

Open `index.html` in a browser, or view it on GitHub Pages.

## Publish on GitHub Pages
1. Create a new repository (e.g. `rfid-ladder`) and upload `index.html`, `.nojekyll` and this README.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch to **main**, folder **/ (root)**, then click **Save**.
4. After about a minute the site is live at `https://<your-username>.github.io/rfid-ladder/`.

The page loads three.js r128 and Google Fonts from public CDNs; nothing else is needed.
